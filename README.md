# JSQT Archive

**Arsip jurnal akademik yang memudahkan pencarian, penelusuran, dan akses artikel ilmiah.**

🔗 **[Buka Live Demo](https://jsqt-archive.vercel.app/)** · [Lihat Repository](https://github.com/Fadhail-3596/jsqt-archive)

## 📖 Tentang Proyek

JSQT Archive adalah proyek web yang dirancang untuk membantu pengguna menelusuri arsip artikel jurnal secara lebih praktis. Melalui satu antarmuka, pengguna dapat mencari artikel, memfilter publikasi berdasarkan subjek dan volume, mengakses halaman artikel atau PDF, serta menyalin sitasi untuk kebutuhan akademik.

Proyek ini berangkat dari ketertarikan saya terhadap pemanfaatan teknologi web untuk membuat informasi akademik lebih mudah diakses dan digunakan.

## ✨ Fitur Utama

- **Pencarian artikel** — Memudahkan pengguna menemukan artikel dalam arsip.
- **Filter subjek dan volume** — Membantu mempersempit pencarian berdasarkan kategori yang tersedia.
- **Akses artikel dan PDF** — Menyediakan tautan menuju halaman artikel dan dokumen PDF yang tersedia.
- **Salin sitasi** — Memudahkan pengguna menyalin sitasi artikel dalam format yang disediakan aplikasi.
- **Antarmuka interaktif** — Membantu pengguna menelusuri koleksi artikel dengan lebih nyaman.

## 🛠️ Pendekatan Pengembangan

Proyek ini dikembangkan menggunakan pendekatan **vibe coding dengan bantuan AI Studio Code**. Saya memanfaatkan AI sebagai pendamping dalam proses pengembangan, mulai dari menerjemahkan ide menjadi antarmuka hingga menyempurnakan pengalaman pencarian dan penelusuran artikel.

Melalui proyek ini, saya mengeksplorasi bagaimana pengembangan berbantuan AI dapat digunakan untuk membangun aplikasi yang memiliki tujuan praktis, khususnya dalam pengelolaan dan akses informasi akademik.

## 🎯 Tujuan Proyek

JSQT Archive merupakan proyek eksplorasi untuk:

- Mengembangkan solusi digital bagi kebutuhan penelusuran informasi akademik.
- Mengeksplorasi pengembangan aplikasi web dengan bantuan AI.
- Mempelajari proses mengubah kebutuhan pengguna menjadi fitur yang dapat digunakan.
